# sawki-legal

Pages légales publiques des applications de Sawki Technologie 2IM, publiées avec GitHub Pages.

| Application | URL |
| :--- | :--- |
| Sawki English | https://raoulib.github.io/sawki-legal/sawki-english/ |
| Sawki English (suppression du compte) | https://raoulib.github.io/sawki-legal/sawki-english/#suppression |

Pour ajouter une application : créer un dossier `<nom-app>/index.html`, puis ajouter un lien dans `index.html`.

Ce dépôt doit rester **public** : Google Play exige que la politique de confidentialité soit accessible sans connexion.
